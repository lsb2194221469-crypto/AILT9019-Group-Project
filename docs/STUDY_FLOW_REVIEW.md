# 操作流程检查与改进 · 2026-11-14

## 修改

- 答题时收起介绍首屏，让题目直接进入视野；移除与“调整出题设置”重复的返回按钮，创建新练习仍从顶部导航进入。

- 原重新练习按钮直接清空作答：新增明确确认框，默认焦点为取消；取消和 Escape 保持原答案、成绩及提交状态，确认后仅清空本套作答。题目、收藏与其他测验保留。
- 新增题号导航：用已答/未答状态区分各题，可直达题目；跳到未答题可聚焦第一个空答案。提交后隐藏未答跳转并更新题号状态。
- 新增题目收藏和只看收藏：在答题及解析阶段均可使用，刷新后保留。筛选没有结果时提供显示全部入口。
- 修复隐藏漏答题的定位：提交遇到漏答时先解除筛选，再显示并聚焦目标题，避免要求填写不可见的输入框。

后端/API/配置/引用/题型/后台任务/公开访问保护共 44 项 Python 回归；前端异常测试覆盖 HTTP、HTML 错误页、无效响应、超时和本地导入失败。

完整历史浏览器回归覆盖上传、补选与清空、独立生成、多标签保存、刷新、删除与取消、活跃记录回退、序号及手机布局。新增 tests/test_study_flow_browser.cjs 在此前流程上验证三类混合题、跳转未答、收藏过滤、隐藏漏答的提交、错题过滤、收藏刷新保留、空筛选、清空确认取消/Escape/确认及收藏保留。

其他回归命令：tests/test_background_browser.cjs（切屏冻结、刷新、关闭标签、断网和丢失提交响应）、tests/test_extra_set_browser.cjs（一键多生成一套）、tests/test_editorial_browser.cjs（桌面平板手机布局）。
