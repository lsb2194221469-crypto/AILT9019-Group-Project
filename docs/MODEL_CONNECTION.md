# 模型连接修复 · 2026-11-13

故障定位：配置的 DeepSeek 模型列表经系统代理访问失败；同一密钥与接口直连成功，模型 deepseek-flash 在返回列表中。系统 HTTPS 代理为本机 127.0.0.1:7897，该端口拒绝连接。

修复：每次模型请求发出前，若代理地址为回环地址，先确认端口能否连接。在明确拒绝连接或两秒内不响应时，使用不带代理的请求处理器。工作中的本机代理、远程代理不会自动绕过；不修改系统设置。代理探测发生在发送 API 请求之前，不重试已发送的出题请求，避免重复消耗额度。HTTPS 校验及禁止转发密钥的重定向保护保持启用。

验证：44 项 Python 测试通过，包含未启动的本机代理、工作中的本机代理和远程代理的四项回归（含本机端口超时）。修复后的生产请求函数已成功查询真实模型列表。本次没有发出付费出题请求；此检查证明接口认证和连通性，不代替完整出题质量验证。

如果本机代理已启动，但上游连接异常，程序会保留该代理；此时请检查代理本身。密钥过期、余额不足和供应商服务故障仍显示相应错误。
