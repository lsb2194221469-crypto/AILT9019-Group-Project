Lecture Lab 本地网页 + DeepSeek API 版（Windows 64 位）

首次使用：
1. 解压整个 ZIP，不要直接在压缩包里运行。
2. 双击 configure.bat，会在记事本打开 config.json。
3. 把 API Key 粘贴到 api_key 后面的空引号中，保留两侧英文双引号。
4. 按 Ctrl+S 保存，关闭记事本。
5. 双击 check_connection.bat 检查 API 连接。
6. 双击 start.bat，网页自动打开 http://127.0.0.1:8765。
7. 点击“重新读取配置”，上传 PDF，用三个滑条分别设置选择、判断、简答题数量。
8. 左侧“我的测验”按出题资料组分栏；点击分栏或具体练习查看，点击“再生成一套”使用本组全部 PDF 继续出题。

config.json 格式：
{
  "api_key": "你的实际密钥",
  "base_url": "https://api.deepseek.com",
  "model": "deepseek-flash"
}

如果你的 Cherry Studio 用的是其他服务商提供的 DeepSeek：
请将 base_url 和 model 改成 Cherry Studio 中同一服务商的接口地址
和确切模型 ID。base_url 必须是 HTTPS，不要填聊天网页地址，
也不要附加 /chat/completions。密钥只对签发它的服务商有效。

使用说明：
- 每种题型可设为 0–12 道，总数为 1–24 道；同一次可以生成混合题。
- 每组最多 10 份 PDF；选好一份后点讲义区域的“继续选择”，可分多次补选。
- 补选会保留已选文件，重复文件自动跳过；取消、读取失败或超过上限不会清空已选文件。
- 点击“创建练习”开始一组新的选择。
- 生成前分多次选择 A、B → 一个分栏；点击“创建练习”后选 C 并生成 → 另一个分栏。每组列出全部 PDF 和测验。
- 给已有测验的组补选 PDF 时，原文件和新文件会另组一组，原测验与作答保留。
- 出题提交后由主机后台完成，切换窗口不会停止；刷新、关闭标签页后在相同网址重新打开也会恢复等待。
- 网络暂时中断会自动尝试取回任务，不会因切屏而重新提交模型请求。
- 主机须保持开机且不进入睡眠；重启主机会中止未完成任务，需手动重试。
- 后台结果保留 24 小时；浏览器取回后的测验仍按本机普通记录保留。
- 同一组可多次生成，不覆盖已有测验；各套题有独立作答进度。
- 每套练习旁的垃圾箱，或工具栏“删除测验”，删除所选整套题及其作答，需确认且无法撤销。
- 删除测验保留 PDF 和其他练习；删除最后一套后仍可用原 PDF 再次生成。
- 多个标签页按记录合并保存，旧页面不会覆盖新增测验；更新后请刷新所有旧页面。
- 文件预览选择只改变预览对象，生成时仍使用本组全部 PDF。
- 旧版记录保留原有分组及作答；新上传的文件按本次批次分组。
- PDF 与测验记录保存在当前浏览器，刷新或重启服务后仍可恢复。
- 清除浏览器站点数据会删除记录；更换浏览器、设备或网址不共享记录。
- 题干、选项、答案及解析支持公式排版（平方、上下标、分数、根号等）。
- 公式渲染和字体已内置，不需要另装 LaTeX，也不依赖外部字体网站。
- 文字型 PDF 会额外根据字形位置读取可识别的上下标，复杂公式仍请核对原页。
- 原文预览和引用保留原始提取文字；点击“打开 PDF 原页”可查看原始公式。
- 更新程序后先关闭旧的启动窗口，重新运行 start.bat，再刷新页面并重新生成题目。
- 不需要安装 Python、Ollama 或本地模型，也不需要部署网站。
- API Key 仅在 config.json 填写，网页没有密钥输入入口。
- 密钥明文保存在你自己的配置文件中，请不要把填好的文件发给别人。
- 网页刷新不会读取配置文件内容给浏览器，只显示配置状态和模型名称。
- API 配置状态不代表余额、密钥或联网已验证；请用连接检查脚本确认。
- 检查连接只请求模型列表，不提交讲义，不生成题目。
- 本地网页仍需联网调用云端模型，费用按你的 API 账户计费。
- PDF 在本机解析；生成时会把选取的文字发送到配置的模型服务。
- 关闭启动窗口停止服务，服务端缓存清空；浏览器本机记录和配置文件保留。
- 示例测验可以直接体验，不调用 API，不是根据上传 PDF 生成的。
- 第三方网关可能不支持模型列表或 JSON 输出，需按其文档确认。

让其他人通过网页使用你的 API 额度（同一局域网）：
1. 关闭原来的启动窗口，双击 share.bat。
2. 将窗口内 Same-network link 后面的链接发给同一 Wi-Fi/局域网的人。
3. 对方在浏览器打开该链接，无需安装软件、无需填写你的 API Key。
4. 你的电脑和启动窗口保持运行。所有出题费用计入你的 API 账户。
5. 若 Windows 提示防火墙访问，允许程序在你信任的网络通信。
此入口是局域网共享，没有登录门槛；跨网络访问需要另外配置。
密钥仅保存在你的电脑配置文件中；不要把填好密钥的文件推到 GitHub。
不同浏览器和访问网址的测验记录各自保存，不自动合并。

访客从 GitHub 直接使用（无需安装或填写 API Key）：
点击仓库首页“打开出题网页”，在网页中上传 PDF 并生成练习即可。
所有调用使用主机的 API Key，扣主机账户的额度。

主机维护公开入口：
- 关闭旧的本地启动窗口，双击 public.bat，保持电脑和服务运行。
- 启动窗口会显示 PUBLIC_URL；本地 README 和“打开出题网页.md”自动更新。
- 首次或重启隧道后，将更新后的入口同步到 GitHub；临时网址每次重启会变化。
- 双击 stop_public.bat 可关闭公开服务与隧道。
- 首次下载隧道工具需要联网；程序会核对官方 SHA-256 后才执行。
- 访客可以在不同网络访问，不需要安装隧道工具。
- 临时隧道不保证持续在线；关闭主机或隧道后无法访问。
