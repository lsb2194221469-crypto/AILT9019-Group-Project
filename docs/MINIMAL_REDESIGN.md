# 极简界面改版 · 2026-11-13

## 设计与操作

白色与暖灰背景、深绿主操作、统一圆角和更清晰的文字层级；减少装饰与重复说明。桌面双栏，窄屏单栏。侧栏历史可滚动，长名称换行；键盘焦点、减少动画偏好和打印样式保留。

新增：按 PDF 文件名或测验名称即时搜索；重命名测验；快速复习/均衡练习/深入理解三种题量预设；Markdown 导出（含答案、解析和出处）；系统打印/存为 PDF。原 JSON 导出保留。打印未提交的题目不会主动展开答案，已展开的解析会随页面打印。

不修改数据库版本、PDF 或测验 ID。重命名使用已有 title 字段；预设使用已有题量设置。历史测验、作答和删除记录兼容旧版。搜索只过滤显示，不删除数据，清空搜索立即恢复列表。浏览器数据按当前站点地址保存，换域名不会自动迁移。

## 完整恢复

本机源代码基线包：`outputs/backups/lecture-lab-before-minimal-2026-11-13.zip`（相对工作区）。密钥、模型配置、运行时、任务记录不进入包，恢复也不覆盖这些数据。

检查基线包：`runtime/python.exe tools/restore_before_minimal.py`

恢复旧代码：先结束正在生成的任务并停止服务，再执行 `runtime/python.exe tools/restore_before_minimal.py --apply`，随后重新启动、刷新页面。该工具先核验 SHA-256、ZIP 完整性和安全解压，每个原始文件逐字恢复，再删除新增的界面功能文件。浏览器历史及新改的名称均可由旧版读取。检查模式不会修改正在使用的文件。

GitHub 另保留改版前分支 `backup/before-minimal-2026-11-13`，可从该分支取回完整旧源代码；无须依赖本机 ZIP。代码恢复不回滚用户在改版期间新增的测验或作答，避免丢失学习记录。
