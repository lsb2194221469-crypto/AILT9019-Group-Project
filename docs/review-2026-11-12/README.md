# 三轮项目检查 · 2026-11-12

本次修复和检查记录一并提交 GitHub；未更新期中提交压缩包。没有调用真实模型或读取、发布 API 密钥。

## 第一轮：功能与数据

检查题型数量、模型输出校验、来源引用、多 PDF、后台任务和历史记录实现。

发现并修复：模型把 type 返回成数组或对象时，字典查找会抛出 TypeError，导致整次生成失败。现在跳过异常条目，保留其他通过校验的题目，仍如实报告题量不足。增加对应回归测试。

继续检查补充：选择题选项原先没有独立长度限制，现限定每项最多 3000 字符，与答案长度上限一致；异常长选项会被拒绝，其他合格题目保留，已添加回归测试。

验证：40 项 Python 单元/HTTP 集成测试通过。首次沙箱执行的本机连接被 WinError 10013 阻止；允许本机测试连接后全套通过，不将环境权限失败记为产品缺陷。

## 第二轮：请求与异常恢复

发现并修复：浏览器请求没有截止时间，连接长时间不返回时，轮询和按钮可能一直等待。新增请求取消和超时提示，后台接口默认 60 秒，旧同步生成接口 330 秒；取消浏览器请求不取消已受理的后台任务，仍使用原任务编号恢复，避免重复计费。

发现并修复：已完成任务的本地导入/显示错误被当成断网，导致反复轮询。现在结束等待并显示实际错误。非 JSON 错误页保留 HTTP 状态，拒绝空值和数组响应，所有分支清理超时计时器。

验证：`node tests/test_client_errors.cjs` 通过，包括成功响应、HTTP 拒绝、HTML 错误页、空响应、超时、计时器清理、本地导入失败终止。

## 第三轮：真实浏览器、界面与启动检查

使用无界面 Edge、本机测试服务及模拟模型。顺序执行现有浏览器回归，避免测试端口冲突。

- `node tests/test_history_browser.cjs`：独立历史、多标签页并发保存、作答保留、删除/取消/Escape、删除后不复活、刷新、序号、PDF 复用、示例重建、清空选择不删除历史、桌面/手机通过。
- `node tests/test_background_browser.cjs`：冻结页面、刷新、关闭标签、断网、提交响应丢失后恢复通过；5 个任务恰好 5 次模拟模型调用，答案持久化通过。
- 浏览器测试未报告页面脚本异常；手机截图已人工查看，公式、按钮和删除确认框可读。
- 检查 start.bat 的便携运行时与 Python 环境入口、固定依赖和 README 的运行说明，未发现需要本次修改的启动逻辑问题。

证据：同目录 history.json、background.json、desktop.png、mobile.png。浏览器使用模拟模型，不能代替真实模型的语义质量评测；旧示例真实 API 证据继续保留，不冒充本次重测。
